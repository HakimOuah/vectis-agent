BRING YOUR MODEL

The judgement stays
with your assistant.

Your MCP-compatible host handles research decisions, fit analysis and scoring using its own supported subscription or API key. Vectis never reads an OpenAI or Anthropic key.

Exa supplies web evidence. Apollo supplies contact discovery and enrichment. Hunter supplies email discovery and verification. Monid connects the data operations, with local receipts and spending limits.

Once the contact handoff is ready, ask your model to draft. Sending is outside this package.

Full setup and client configuration ↗
TERMINAL 
git clone https://github.com/HakimOuah/vectis-agent.git
cd vectis-agent
npm ci --ignore-scripts
cp .env.example .env
chmod 600 .env

Add your Monid key and spending cap to the private .env file, then connect the MCP server using the README. Ask your assistant to call vectis_get_workflow first.

Know the boundaries.

Client compatibility. Codex authenticated through ChatGPT and read the tools. Its unattended approval policy blocked mission creation, so that autonomous path is not yet validated. Claude remains untested.

What this replaces. A sponsorship prospecting workflow, not the entire Apollo or Hunter products. Both remain upstream providers through Monid. No subscription savings or feature parity claim is established.

What ships today. Installable local tools, persistent evidence and budgets, verification checks and report handoff. No hosted connector, CRM synchronization or email sending.
